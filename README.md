# مشعل الدواس — صفحة شخصية (Portfolio)

🔗 **الموقع مباشرة:** [c9mx1188.github.io/Meshalaldawas](https://c9mx1188.github.io/Meshalaldawas/)

صفحة شخصية لمبرمج مبتدئ من الرياض، توثّق المسار التعليمي، المهارات، المشاريع، وأكثر من 50 شهادة تدريبية. مصممة بأسلوب "مخطط هندسي" (Blueprint) مستوحى من خلفية صاحبها في الرسوم التقنية.

---

## المميزات

- **ثنائية اللغة**: زر تبديل فوري بين العربية (RTL) والإنجليزية (LTR) — يحفظ اختيار الزائر.
- **شهادات قابلة للتصفح**: أكثر من 50 شهادة مقسّمة على 7 مجموعات قابلة للطي (تطوير الويب، تحليل البيانات، Excel، إدارة المنتجات...) مع زر "توسيع الكل / طي الكل".
- **مشاريع حقيقية**: بطاقات تربط مباشرة لمستودعات GitHub.
- **نموذج تواصل شغّال**: عبر [Formspree](https://formspree.io) بدون سيرفر خلفي.
- **موسيقى خلفية اختيارية**: تشغيل/إيقاف مع متحكم مستوى صوت بتصميم نيون.
- **أنيميشن وتفاعلات خفيفة**: ظهور تدريجي عند التمرير، فتح/إغلاق سلس للشهادات — كل شي يحترم إعداد تقليل الحركة (`prefers-reduced-motion`).
- **متجاوبة بالكامل**: تعمل على الجوال والديسكتوب.
- **جاهزة للمشاركة**: وسوم OpenGraph وTwitter Card مع صورة معاينة مخصصة.

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| **HTML5** | بنية الصفحة الدلالية (Semantic) |
| **CSS3** | التصميم، الشبكات (Grid/Flexbox)، الأنيميشن، التجاوب |
| **JavaScript (Vanilla)** | التفاعلات، تبديل اللغة، نموذج التواصل، مشغل الموسيقى |
| **Formspree** | استقبال رسائل نموذج التواصل بدون Backend |
| **GitHub Pages** | الاستضافة |
